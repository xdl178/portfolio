# 离线设计管理器

## 使用

1. 用桌面版 Chrome 或 Edge 双击打开根目录的 [design-manager.html](<../design-manager.html>)。它不需要 npm、后台或本地 HTTP 服务，也没有网站导航入口。
2. 点击“选择项目文件夹”，选择包含 [参数清单](<../design-system.schema.json>) 的项目根目录，允许浏览器读写该目录。浏览器可能在重新打开工具后要求再次授权。
3. 搜索或选择分组，修改颜色、字号、间距、圆角、动效等参数。右侧先预览，未点保存不会改项目。
4. 点击“保存到项目”。真正的样式源是 [design-system.css](<../public/design-system.css>)，不是浏览器 localStorage。网站通过独立 stylesheet 加载它。
5. 勾选同步选项且构建副本已存在时，工具同时更新 `dist/design-system.css`。当前本地预览刷新即可看到效果，无需重新打包。没有构建副本时只保存源文件；首次网站构建仍需正常运行 `npm run build`。部署仍需上传修改后的文件，不会自动推送 Git。

工具不上传文件，不从 CDN 加载依赖。Safari、Firefox 或不支持 File System Access API 的环境无法直接写项目，会明确禁用连接和保存；仍可预览并导出 CSS，再手动替换源样式。

## 参数范围

当前提供 130 项实际被项目消费的参数，分为 13 组：色彩、字体、动效、布局、响应式边距、章节标题、胶囊标签、作品标签、信息卡片、操作按钮、个人资料、联系页脚、指针高光。

- `--brand-rgb` 等保持 RGB 通道，页面背景等保持 HSL 通道，副文本保持 HEX；颜色选择器负责转换，不会混用格式。
- `--brand`、`--accent` 等派生别名只保留在 CSS 中，不另设可能失联的控制项。
- 未被现有页面使用的旧变量保留原值，但不显示为可编辑功能。
- 清单中的 `default` 是交付时的重置基线；连接项目后始终读取 CSS 当前值，不用默认值覆盖你的修改。
- 组件内容、结构、路由和 JS 业务逻辑仍由源代码管理，工具不伪装成任意组件代码编辑器。

## 预览边界

工具内嵌默认参数和共享组件 CSS，可独立离线打开。连接项目后读取实际组件样式；预览内容与编辑器本身隔离，改成低对比度配色也不会让保存、撤销按钮消失。默认/悬停等 CSS 状态可预览；React 路由、滚动入场和实时指针逻辑请在网站上检查。字体使用当前环境可用的字体栈回退，不会通过网络下载字体。

## 文件安全与恢复

- 点击保存前比较磁盘内容与读取快照；遇到外部修改会停止，不会静默覆盖。
- 保存前在项目根目录 `.design-backups/` 创建旧 CSS 备份，构建副本同步前也单独备份。该目录已忽略 Git。
- 每个文件使用浏览器 writable stream 提交。跨源/构建两个文件并非操作系统级原子事务；后续写入失败会尝试回滚已写文件，失败时明确提示使用备份恢复。
- “下载备份”可下载本次保存前的源样式；“导入方案 / CSS”只导入已知参数到草稿，确认后才保存。
- “撤销草稿”回到本次读取/保存后的值；“本组恢复默认”只改当前组草稿。
- 不接受规则注入、外部 URL、未闭合 CSS 函数或注释。普通文本参数按字体栈、缓动曲线或圆角的 CSS 属性语法验证。
- 切换项目失败不会替换原项目的目录、草稿、快照或备份；读取与保存期间禁用编辑，避免并发操作。

## 全局标题组件

[SectionHeading](<../src/components/SectionHeading.tsx>) 与[样式](<../src/components/SectionHeading.css>) 是首页 `01 ABOUT / 关于我` 结构的唯一实现：序号、英文底字、斜线、中文标题及强调色。组件API保留语义层级、标题 ID、副标、右侧动作和原有入场 props；使用范围仅限章节分界，不应用于页面主h1。

仅页面章节分界接入：首页关于我/作品/工作经验、关于我页导读/优势/联系（01..03）。作品档案与关于我页面h1独立保留HEAD旧版居中单行巨字：clamp(2.8rem,11vw,8.4rem)、600字重、1.04行高、-.05em字距、nowrap及text-gradient强调；不接入SectionHeading，不受--heading-*控制。Works导读heading整块移除，仅保留正文和统计。[SectionHeader](<../src/components/SectionHeader.tsx>) 仅作为旧调用兼容层转发到该组件。卡片内部标题、正文宣言、Hero 字形和页脚 CTA 保留内容层级，不强制加章节编号。

所有 `--heading-*` 参数集中在同一 CSS 中，仅控制章节分界标题，不改变独立页面h1。旧 `selected-works-*` 标题类仅保留兼容别名，原重复标题 CSS 已移除。长英文底字可裁切以避免窄屏溢出，中文实际标题不裁切。

## 开发与验证

- `npm run test:design-manager`：参数清单/消费关系、工具真实磁盘写入隔离测试、离线与错误状态、全站共享标题行为。
- `npm run build` 的 prebuild 会运行 [种子同步脚本](<../tools/sync-design-manager.mjs>)，更新 HTML 内置的默认示例；使用工具时不需要该脚本或 Node。
- 工具自动测试只替代不可自动点击的浏览器目录选择器；后续读写桥接到隔离的真实临时目录，断言保存结果、备份、构建副本、外部冲突、非法值和失败项目切换。未声称自动验证操作系统原生授权弹窗。
- 既有视觉回归仍校验交付默认设计；自行改设计参数后，涉及原始精确数值的视觉断言可能需要按你的新设计基线更新。
