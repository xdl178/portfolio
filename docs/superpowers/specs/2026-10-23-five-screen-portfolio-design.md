# 五屏作品集重构设计说明

## 意图与边界

在独立项目 `portfolio-landing-next` 上重新梳理首页，让访问者按「视觉印象 → 人物框架 → 作品证明 → 方法与项目类型 → 简介及联系」阅读。保留已有首屏组件和背景图片，不修改首屏的视觉布局、动效或文字；续接四段具有连续编号和清晰节奏的深蓝科技视觉。沿用 React + TypeScript + Tailwind、Framer Motion、GSAP 现有技术栈。`portfolio-test` 只作为内容组织和作品图片的参考，不复制其个人资料或暖色视觉。

## 决定与非目标

- 五屏顺序固定：①原首屏；②「01 关于我」；③「02 精选作品」；④「03 项目经验」；⑤「关于我与联系信息」。第五屏之后可保留短小版权脚注，但不再出现第六个等重内容屏。首页现有独立画廊不再单独占屏，其图像入口并入精选作品区或作品详情；详情页现有灯箱仍保留。
- 第二屏参照用户提供的深色双栏图片：左上有 `01 / 关于我` 叠字刊头，左列大比例浅灰圆角人物照片占位块，右列纵排资料组（基本信息、教育背景、工作经历），视觉和字阶可优化而非像素复刻。占位块明确标注「照片待补充」，无杜撰人物照。屏幕较窄时改单列，标题与占位图优先。
- 姓名、所在地、教育学校/专业/年份、任职机构/岗位/时间、个人简介、作品站、邮箱、电话与任何社交账号都只显示清晰的「待补充」占位；不把截图或 `portfolio-test` 中可辨认的姓名、学校、邮箱等资料引入新首页、关于页、全局导航、页脚或 metadata。尚未给出可用邮箱时，联系按钮应跳转到第五屏的联系占位区域，不能链接到既有或虚构邮箱；占位文字不是可点击的假链接。
- 第三屏复用当前三件精选作品、封面图片和详情路由：原创 IP、艺术工作室品牌网站与 AI 产品网站。卡片仍可点击真实详情，展示视觉与过程，不将作品作者信息推断为用户身份。作品浏览入口与画廊图可融入这里；移动端流畅单列。
- 第四屏不使用参考项目中的具体地名、客户名和无法核对的成果数字。以「公共空间体感互动」「智能健康终端」「园区数字服务」等匿名项目类型说明设计问题、可观察的交互方法与交付形态；文案不能暗示项目已真实上线、某人主导或获得特定商业成果。可做三张叙事卡/分段列表，保留技术感与编号，不伪造案例图；资料不足处标注示意。
- 第五屏按参考项目的组织方式提供简短简介占位、能力方向概述与联系信息占位。视觉上以大排版、分隔线和一块克制的联系区域收尾；不做假发送成功的表单、不输出假联系方式。全局页脚精简，避免与第五屏重复且避免真实身份资料泄露。`/about` 页面同步保持占位策略，不能继续展示旧履历、奖项与真实邮箱。
- 顶部导航现有「首页 / 精选作品 / 关于我 / 联系我」保留标签，首页内可优先锚定对应屏幕，其他路由通过首页哈希或链接回访；品牌首屏组件保持原件。其余路由 `/works`、`/works/:id` 和 `/about` 仍可正常使用。
- 动效限于有意义的进场和层次：第二屏标题与资料轻微错位揭示、占位照片轻微景深；作品卡 hover 和聚焦响应；经验卡在宽屏滚动叙述时允许 GSAP pin/scrub；第五屏简洁渐显。桌面滚动动画只在宽屏且无 reduced motion 时运行，触屏和减少动态效果下内容静态可达；禁止连续强制平滑滚动、遮挡文本、无限耀斑。键盘导航、对比度与焦点态保留。

## 结构与验收

- 首页 DOM 仅有五个主要连续区段，按上述顺序；第二、三、四区段显示 `01`、`02`、`03` 章节编号。首屏 `Hero.tsx` 与背景资源二进制哈希和本次改动前一致。
- 第二屏的人物照片是明显占位；所有个人资料及联系信息在首页、关于页、全局导航与页脚都不出现先前的真实数据或虚构链接。已获准的三个精选作品与图片继续显示、可进入详情。
- 第四屏没有具体客户地名、未核实合作成果和虚构案例图；第五屏同时能看到简介与联系入口占位。
- 桌面 1440px、手机 390px 无横向溢出；所有五屏可滚动抵达，锚点、作品详情和返回均工作；减少动态效果下无 pin 内容遮挡；页面无图片 404、运行时错误；TypeScript 与生产构建通过。

## 留给实现者的取舍

章节图片与文本细节、字重和空间节奏沿用现有深蓝设计 token，并按参考截图的双栏比例进行审美微调。先清查所有既有个人资料（包含页面元数据及导航邮件），再集中管理占位字段，避免遗漏；保留现有作品数据与真实图片，不把资料归属延伸至个人身份。当前独立项目无 `.git`，本说明无法提交 commit；若未来初始化仓库，再与代码一并纳入版本控制。
