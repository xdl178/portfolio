# 占位与隐私范围

## 当前内容策略

- 首页与关于页的姓名、地址、生日、学校、毕业时间、联系方式、可到岗时间、个人介绍、经历及能力说明均使用“待补充”。个人概览值使用破折号，不展示未经确认的成就数字。
- 关于页仅保留01导读、02优势、03联系；删除导读联系按钮和整个奖项章节及数据。联系卡为普通展示，不产生指向占位值的邮箱/电话链接。
- 首页项目经验使用三组占位；作品日期、周期与个人职责也为占位。作品标题/品牌、软件名及第三方来源和字体许可证不属于本人联系方式，保留其内容与必要署名。
- 项目资料入口使用共享[FooterNavLink](<../src/components/FooterNavLink.tsx>)，不复制一套页脚动效样式。

## 验证

`npm run test:privacy`检查运行时源码中的邮箱/手机号、个人介绍及经历占位、项目日期/职责、已删除奖项，以及作品集入口与页脚的样式/交互一致性。`npm run test:about-page`保护三个章节、占位联系与独立页面主标题。构建后再检查发布文件及预览。
